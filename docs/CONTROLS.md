# Controls

| Input                 | Action                                                                |
| --------------------- | --------------------------------------------------------------------- |
| W A S D or arrow keys | Move                                                                  |
| Space                 | Jump; hold to bunny hop                                               |
| Shift                 | Dodge                                                                 |
| Mouse                 | Aim; left fires, right uses the weapon's second mode                  |
| 1 to 6, wheel         | Rifle, shotgun, grenade launcher, rocket launcher, spark gun, railgun |
| Middle button         | Previous weapon                                                       |
| V                     | Kick                                                                  |
| F                     | Juggle; press again for the next trick                                |
| 7                     | Special from a crate                                                  |
| E (hold)              | Hook onto overhead roofs/platforms or places you cannot walk to       |
| Tab (hold)            | Scores                                                                |
| Esc                   | Menu                                                                  |
| U                     | Apply an offered code update                                          |

In the pause menu, **Invert mouse (vertical)** reverses mouse look up/down and is remembered in this browser. Touch and gamepad aiming keep their own directions.

On touchscreens, the left thumb moves and the right thumb looks. Fire, Jump, Hook and Next are buttons. For a higher rocket jump with two thumbs, aim down, tap Jump, then Fire.

On a gamepad, the left stick moves (click to dodge), the right looks (click to kick), triggers fire/alt-fire, A jumps, B dodges, X hooks, bumpers switch weapons, Back shows scores, and Start opens the menu.

Rocket jump: aim the rocket launcher down at nearby ground and fire. Its pressure burst throws you away from your aim without damage or breaking the floor. Jump while firing for extra height. It costs one rocket and uses the normal firing cooldown. Forward shots launch rockets; alt-fire launches a mortar.

The crosshair shows **Rocket jump** when primary fire will become a safe pressure burst. A brief first-use card explains each weapon, fades out, and remembers what you have learned on this browser. Tips name the active controls; touch tips describe primary fire. Losing focus or disconnecting the gamepad releases held controls and returns to the menu.
